AI SAST Agent: Enhancing SAST Accuracy and Context-Awareness via RAG

Problem Statement:

Traditional Static Application Security Testing (SAST) tools rely on predefined rules to identify vulnerabilities but struggle with context-dependent logic flaws and high volumes of false positives. While Large Language Models (LLMs) help audit code, they suffer from static knowledge and a lack of awareness regarding specific enterprise coding standards.

The Gap between AI and security:

1. Static Knowledge Base: Standard LLMs cannot stay updated with the latest zero-day vulnerabilities.
2. Lack of Organizational Context: General AI models are unaware of internal security policies.
3. Hallucination in Patching: AI agents often suggest non-existent libraries or insecure patterns.

Proposed Solution:

Build an AI Security Agent using RAG (Retrieval-Augmented Generation) to connect source code to a live library of security knowledge like Latest CVE Databases, ensuring context-aware and verified remediation advice.
